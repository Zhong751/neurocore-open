# Blank character package

Copy this directory and fill `character.json` and `seed.md` using
[the seed guide](../../docs/seed_guide.md). The bracketed instructions are blank
fields, not an official character voice. The template is structurally valid so
the CLI can be tried without an image or a model connection.

Images, animation and other optional assets are made or supplied by the user.
No formal Zealor voice or art is included or authorized for publication. Keep
personal assets and instances outside tracked source; binary publication is
still excluded by the repository scanner. A local file is not, by itself,
permission to redistribute it.
